# Google Search Console Actions

Run these after nginx prerender checks pass.

## 1) Submit sitemap

1. Open Search Console property for `https://makemystay.ai/`.
2. Go to **Sitemaps**.
3. Submit: `https://makemystay.ai/sitemap.xml`.

## 2) Request indexing for priority URLs

Use **URL Inspection** and click **Request indexing** for:

- `https://makemystay.ai/`
- `https://makemystay.ai/pg/bangalore`
- `https://makemystay.ai/rent/bangalore`
- `https://makemystay.ai/faq`
- `https://makemystay.ai/blog/pg-in-bangalore-guide`
- `https://makemystay.ai/blog/pg-near-whitefield-bangalore`
- `https://makemystay.ai/blog/pg-checklist-new-joiners-bangalore`

## 3) Rich Results validation

Use Google Rich Results Test for:

- `https://makemystay.ai/` (expect Organization / LocalBusiness + WebSite graph)
- `https://makemystay.ai/faq` (expect FAQPage)
- `https://makemystay.ai/pg/bangalore` (expect FAQPage + BreadcrumbList)
- `https://makemystay.ai/rent/bangalore` (expect FAQPage)
- `https://makemystay.ai/blog/pg-in-bangalore-guide` (expect Article + FAQPage + BreadcrumbList)
- `https://makemystay.ai/blog/pg-near-whitefield-bangalore` (expect Article + FAQPage + BreadcrumbList)
- `https://makemystay.ai/blog/pg-checklist-new-joiners-bangalore` (expect Article + FAQPage + BreadcrumbList)

## 4) Monitor

For 2–4 weeks, monitor:

- Indexed pages trend up
- “Crawled - currently not indexed” trend down
- Impressions/clicks for PG and rent hubs trend up

## 5) External citation distribution (AEO)

Complete these after index requests are submitted:

1. Quora: answer 5-10 PG/Bangalore questions and naturally cite `makemystay.ai` guides.
2. Reddit: publish helpful posts in `r/bangalore`, `r/india`, and `r/digitalnomad` with contextual links.
3. Directory listings: create/update profiles on JustDial and Sulekha with homepage + PG Bangalore link.
4. Guest mentions: secure 1-2 Bangalore lifestyle blog mentions and link at least one of the new guide URLs.
